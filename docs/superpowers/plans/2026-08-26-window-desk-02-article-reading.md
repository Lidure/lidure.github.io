# Window Desk Redesign 02: Article Reading Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn article pages into quiet long-form reading pages with an accessible H2/H3 table of contents, scrollspy, mobile disclosure, stable reading progress, and typography that matches the new semantic design foundation.

**Architecture:** Extract heading selection into a pure helper, render desktop/mobile TOC through one `ArticleToc.astro` component, and keep the existing article body independent from JavaScript. The TOC controller uses heading IDs already generated by Astro, updates current-section state and URL hash, and owns cleanup across Astro view transitions. New `article.css` is loaded after the legacy `article-reading.css` during migration; Plan 04 removes the old file after all article behavior is covered.

**Tech Stack:** Astro 6 content rendering, TypeScript/Astro component scripts, CSS, Node built-in test runner, existing `estimateReadingMinutes` utility and Comments component.

**Spec:** `docs/superpowers/specs/2026-08-26-window-desk-tide-paper-design.md`

## Global Constraints

- TOC uses Markdown H2 + H3 only; H3 is visually nested.
- Hide the TOC when fewer than 2 eligible headings exist.
- Desktop: left sticky TOC, active-section theme accent, long TOC scrolls independently.
- Mobile: collapsible TOC before body; clicking a section closes it and jumps to the heading.
- URL hash follows explicit TOC navigation; anchor links remain functional without JavaScript.
- Respect `prefers-reduced-motion` and `document.documentElement.dataset.reduceMotion`.
- Article reading width is 720–760px; use `--reading-max` from Plan 01.
- Tags remain `#标签` text, not pills.
- Quotes use a thin rule, code remains monospace, tables use lines/spacing rather than card chrome.
- Images may naturally break wider than text on desktop; no mandatory rounded shadow treatment.
- Comments remain operational and visually secondary after the article end marker.

- [ ] **Step 3: Add the controller**

Inside `ArticleToc.astro`, add one client script with this lifecycle shape:

```ts
const tocWindow = window as typeof window & {
  __articleTocCleanup?: () => void;
  __articleTocLifecycleBound?: boolean;
};

function initArticleToc() {
  tocWindow.__articleTocCleanup?.();
  const article = document.querySelector<HTMLElement>('.article-publication');
  const prose = article?.querySelector<HTMLElement>('.article-prose');
  const links = Array.from(article?.querySelectorAll<HTMLAnchorElement>('.article-toc-link') ?? []);
  if (!article || !prose || !links.length) return;

  const controller = new AbortController();
  const { signal } = controller;
  const ids = [...new Set(links.map((link) => link.dataset.articleHeading).filter(Boolean))];
  let frame = 0;

  const sync = () => {
    frame = 0;
    const proseRect = prose.getBoundingClientRect();
    const start = window.scrollY + proseRect.top;
    const end = start + prose.offsetHeight - window.innerHeight;
    const progress = Math.min(1, Math.max(0, (window.scrollY - start) / Math.max(1, end - start)));
    article.style.setProperty('--article-reading-progress', String(progress));

    let currentId = ids[0] ?? '';
    const threshold = Math.min(180, window.innerHeight * 0.28);
    for (const id of ids) {
      const heading = id ? document.getElementById(id) : null;
      if (heading && heading.getBoundingClientRect().top <= threshold) currentId = id;
    }
    for (const link of links) {
      link.classList.toggle('is-current', link.dataset.articleHeading === currentId);
    }
  };

  const requestSync = () => {
    if (frame) return;
    frame = requestAnimationFrame(sync);
  };

  for (const link of links) {
    link.addEventListener('click', (event) => {
      const id = link.dataset.articleHeading;
      const heading = id ? document.getElementById(id) : null;
      if (!id || !heading) return;
      event.preventDefault();
      const reduced = window.matchMedia('(prefers-reduced-motion: reduce)').matches
        || document.documentElement.dataset.reduceMotion === 'true';
      heading.scrollIntoView({ behavior: reduced ? 'auto' : 'smooth', block: 'start' });
      history.replaceState(null, '', `#${encodeURIComponent(id)}`);
      const details = link.closest('details');
      if (details) details.open = false;
    }, { signal });
  }

  window.addEventListener('scroll', requestSync, { passive: true, signal });
  window.addEventListener('resize', requestSync, { passive: true, signal });
  tocWindow.__articleTocCleanup = () => {
    if (frame) cancelAnimationFrame(frame);
    controller.abort();
  };
  sync();
}

if (!tocWindow.__articleTocLifecycleBound) {
  tocWindow.__articleTocLifecycleBound = true;
  document.addEventListener('astro:page-load', initArticleToc);
  document.addEventListener('astro:before-swap', () => tocWindow.__articleTocCleanup?.());
}
initArticleToc();
```
