这是我的第一篇博客文章。

这个站点现在具备了三个基础能力：

- Markdown 写作
- 文章归档和详情页
- GitHub Actions 自动部署到 GitHub Pages

后续只需要在 `src/content/blog/` 里继续新增 Markdown 文件，就可以持续写作。

## 现在的功能

1. 接入评论系统
2. 做标签页和搜索
3. 加入了碎碎念，偶尔用来即时发布我的动态
4. 绑定了自定义域名，部分后端接入API，部分存储与cf r2
5. 娱乐——新增了“沉浸”页面，提供弹幕发送（每首歌都不一样哦），欢迎发送弹幕！音频可视化，隐藏等功能
6. 娱乐——添加了音乐功能（右下角）：包括几乎全部的pjsk的音乐，提供了音频可视化。可以自行上传歌曲或者在线歌单。
7. 娱乐——添加了背景设置（左上侧）：提供了一些背景，包括视频背景和图片背景，也可以自行上传。可以进行轮播等功能。
