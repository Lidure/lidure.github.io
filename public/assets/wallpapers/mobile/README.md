# Mobile wallpapers / 手机端背景库

把竖屏壁纸放在这个目录中，博客构建时会自动将图片加入手机端默认背景库。

- 推荐比例：9:16；常用分辨率：1080×1920 或更高。
- 图片格式：JPG、PNG、WebP、AVIF（构建时生成响应式 WebP 版本）。
- 可以使用 MP4 视频，但手机浏览器会优先显示静态封面以减少耗电和播放兼容问题；建议优先使用图片。
- 推荐使用唯一的英文数字文件名，避免同名和特殊字符。请勿把电脑端壁纸移到这里：两个库是独立的。
- 未上传任何手机背景时，网站会自动回退到原来的电脑背景库。

网页“背景库”中的自定义上传仅保存在当前浏览器；要让所有访客都看到新背景，需要把文件提交到这个 GitHub 目录并完成部署。
