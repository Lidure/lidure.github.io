  3. 发送对应的看图命令。例如 看123，就会取出编号 123 的原图。

🎁 怎样抽多张表情？

想从所有分类随机抽 5 张（不是只从 airi 分类抽），发送：

/抽表情 5

分类批量看图与全库抽表情是两种功能。单次张数受插件设置和图库实际图片数量限制。

🔍 为什么提示相似或重复图片？

为避免重复收录，画廊会检查同分类的完全重复图和感知相似图。完全重复的图片不能强制上传；如果只是“相似”但内容确实不同，可以在出现确认提示后使用：

/强制上传

只用于确认最近一次被判定为“相似”的图片，通常需在 5 分钟内执行；确认上传成功后才会计入个人贡献。失败或无效图片不会增加数量。

🗂️ 图库整理、跨分类迁移（管理功能）

想整理已有图片，可以请有权限的管理员使用 /迁移图片，按编号预览后再用 /确认迁移图片 N 确认，或打开 AstrBot WebUI 的图库管理页面按缩略图移动。移动前会再次校验图片及远程同步状态，避免覆盖原图。

这里的 N 是迁移预览给出的实际数量。普通看图和个人贡献查询不需要管理权限；管理操作是否对群成员开放取决于插件的 use_permission 设置。

② 什么是「绑定 UID」？
  1. 在游戏里打开角色资料页，找到你的 UID（一串数字）。
  2. 选择对应游戏的绑定命令，把自己的 UID 接在命令后面。例如原神：gs绑定uid123456789。
  3. 上面的 123456789 只是格式示例，不是你的 UID。请换成你游戏里的真实数字再发；不要直接照抄示例号码。

不同游戏的命令前缀不同：原神 gs、星铁 sr、绝区零 zzz、崩坏 3 bbb。例如崩坏 3 使用 bbb绑定uid 后接自己的 UID。各游戏的 UID 不能混用。

🎁 米游社：原神 / 星铁 / 绝区零 / 崩坏 3 自动签到

这四款游戏都可以在米游社社区签到。绑定 UID、授权米游社、开启自动签到是三个不同步骤。

  1. 绑定自己的 UID：先使用对应游戏的 绑定uid 命令。例如原神可以参照上面的 gs绑定uid123456789 格式，换成自己的 UID。
  2. 完成米游社授权：建议私聊小浅子发送 扫码登录，根据 Bot 返回的二维码提示，用自己的米游社账号完成授权。先绑定至少一个米哈游游戏 UID 才能开始扫码。
  3. 开启你要玩的游戏的自动签到：在 QQ 中发送下方与游戏相对应的命令。玩几款，就分别开启那几款，不是所有游戏自动共用一个开关。
  4. 看 Bot 的确认消息：收到已开启的回复后，后续由 Bot 定时尝试签到；需要验证可在对应游戏帮助里找到手动签到命令。
下面是能直接发送的开关指令

🌊 库街区：鸣潮自动签到

  3. 之后可以发送 ww帮助 查看签到日历、签到结果订阅等其他功能。

🌐 异环：社区自动签到

🔐账号安全：UID 是角色识别号码；但密码、短信验证码、Cookie、Token 不要发到群里。只在可信的账号授权页面或 Bot 私聊登录流程中操作。自动签到属于尝试执行，不能保证每天一定成功。

排行榜命令需要写模式；直接发送 /pixiv_ranking 会先显示帮助，不是立即取榜单。常用模式为 day（日榜）、week（周榜）、month（月榜）。

🖼️ 知道作品 ID，怎么查看作品或相似图？
  1. 打开 Pixiv 的作品链接，找到其中的作品 ID（数字），而不是画师的用户 ID。
  2. 在 QQ 中输入 /pixiv_specific，再输入一个空格和作品 ID，即可查询该作品详情。
  3. 如果想找相关作品，用 /pixiv_related 加同一个作品 ID。

例如指令格式为“/pixiv_specific + 空格 + 作品 ID”。必须替换成真实作品 ID，因此这里不提供复制假号码的按钮；复制前先确认不是画师 ID。

🔔 想关注喜欢的画师，自动接收更新？
  1. 先用 /pixiv_user_search 加画师名搜索，找到画师用户 ID。
  2. 发送 /pixiv_subscribe_add 加一个空格及该画师用户 ID，按 Bot 提示订阅。这个指令会改变当前订阅状态。

👍 点赞小浅子的 QQ 资料卡，会自动回赞吗？

会尝试回赞。当你给小浅子资料卡点赞、Bot 正常收到 QQ 的点赞通知后，就会尝试给你的资料卡回赞，无需发送命令。

当前按每位用户每天最多尝试一轮处理，单轮最多尝试 50 个赞。实际成功数量受 QQ 每日限额、双方关系与接口权限限制，重复点赞不会无限触发。

另外，发送 赞我 可以主动请求名片赞，/订阅点赞 可尝试订阅每日点赞。这需要用户主动操作，和收到赞后的自动回赞不同。

05 · LITTLE TIPS

还有一点小提醒

遇到问题时，不用着急。

命令发送后没有回复？按这几步检查
  1. 核对前缀：例如 /查看贡献、/查看画廊、/上传airi 要带斜杠；看airi 通常不用。注意空格与命令写法。
  2. 确认使用场景：群聊中与 AI 聊天要真正 @机器人；上传图片需要回复那条图片消息，不能单独发送上传命令。
  3. 检查服务状态：确认机器人仍在 QQ 群内、没有离线；部分游戏和远程节点服务可能暂时不可用。
  4. 检查权限与限制：部分群不允许上传，或存在调用频率限制。/查看贡献 只查询自己的 QQ 投稿记录，新功能启用前的旧图不会计入。
  5. 仍无回复：可以向管理员提供发送时间、群聊或私聊场景、命令原文与报错截图，方便查日志；不要发送密码、Cookie 或验证码。

找不到具体指令时，先在上方搜索框输入完整命令；也可以在 QQ 尝试 /画廊帮助 或 /help 查看相应帮助。

游戏查询或自动签到提示未绑定？

绑定游戏 UID 和登录游戏社区是两回事。进入「游戏工具」展开对应社区的自动签到教程，按步骤登录、开启。

为什么有时回复很慢？

AI、语音、Pixiv 和游戏数据都依赖外部接口。服务繁忙或网络波动时可能变慢甚至暂时不可用。

找不到想要的功能？

使用上方的命令搜索输入完整命令（例如 /上传airi）或功能词（例如 签到），可直接跳到对应说明；也可在 QQ 发送 /help，或去博客留言板反馈建议。
