② 什么是「绑定 UID」？
  1. 在游戏里打开角色资料页，找到你的 UID（一串数字）。
  2. 选择对应游戏的绑定命令，把自己的 UID 接在命令后面。例如原神：gs绑定uid123456789。
  3. 上面的 123456789 只是格式示例，不是你的 UID。请换成你游戏里的真实数字再发；不要直接照抄示例号码。

不同游戏的命令前缀不同：原神 gs、星铁 sr、绝区零 zzz、崩坏 3 bbb。例如崩坏 3 使用 bbb绑定uid 后接自己的 UID。各游戏的 UID 不能混用。

🎁 米游社：原神 / 星铁 / 绝区零 / 崩坏 3 自动签到

这四款游戏都可以在米游社社区签到。绑定 UID、授权米游社、开启自动签到是三个不同步骤。

  1. 绑定自己的 UID：先使用对应游戏的 绑定uid 命令。例如原神可以参照上面的 gs绑定uid123456789 格式，换成自己的 UID。
  2. 完成米游社授权：建议私聊小浅子发送 扫码登录，根据 Bot 返回的二维码提示，用自己的米游社账号完成授权。先绑定至少一个米哈游游戏 UID 才能开始扫码。
  3. 开启你要玩的游戏的自动签到：在 QQ 中发送下方与游戏相对应的命令。玩几款，就分别开启那几款，不是所有游戏自动共用一个开关。
  4. 看 Bot 的确认消息：收到已开启的回复后，后续由 Bot 定时尝试签到；需要验证可在对应游戏帮助里找到手动签到命令。
下面是能直接发送的开关指令
扫码登录 gs开启自动签到 sr开启自动签到 zzz开启自动签到 bbb开启自动签到

如果提示未绑定 UID，先完成第 1 步；如果提示没有 Cookie / 授权失效，重新执行扫码登录。米游社的社区签到与游戏内每日任务不同；网络或风控验证码可能导致当天签到失败。

🌊 库街区：鸣潮自动签到

  2. 登录后，发送 ww开启自动签到，根据回复确认当前账号已加入自动签到。
  3. 之后可以发送 ww帮助 查看签到日历、签到结果订阅等其他功能。
ww登录ww开启自动签到

鸣潮的库街区账号与米游社不是同一套登录。若与手机 App 出现互相挤下线或登录失效，请按返回提示重新授权。

🌐 异环：社区自动签到
  1. 私聊小浅子发送 nte登录，通过返回的网页链接完成异环账号绑定。
  2. 发送 nte开启自动签到，以 Bot 返回的成功提示为准。
  3. 想马上检查当日签到？可以发送 nte签到 手动执行一次。

🔐账号安全：UID 是角色识别号码；但密码、短信验证码、Cookie、Token 不要发到群里。只在可信的账号授权页面或 Bot 私聊登录流程中操作。自动签到属于尝试执行，不能保证每天一定成功。

🎨 Pixiv 新手：搜索、推荐与画师

🏆 Pixiv 排行榜：日榜、周榜、月榜

排行榜命令需要写模式；直接发送 /pixiv_ranking 会先显示帮助，不是立即取榜单。常用模式为 day（日榜）、week（周榜）、month（月榜）。

查看周榜

查看月榜

查看全部排行榜参数
/pixiv_ranking help

也可以在模式后加日期（格式 YYYY-MM-DD），但需要输入真实存在的榜单日期。网站内容过滤模式会限制部分排行榜。

🖼️ 知道作品 ID，怎么查看作品或相似图？
  1. 打开 Pixiv 的作品链接，找到其中的作品 ID（数字），而不是画师的用户 ID。
  2. 在 QQ 中输入 /pixiv_specific，再输入一个空格和作品 ID，即可查询该作品详情。
  3. 如果想找相关作品，用 /pixiv_related 加同一个作品 ID。

例如指令格式为“/pixiv_specific + 空格 + 作品 ID”。必须替换成真实作品 ID，因此这里不提供复制假号码的按钮；复制前先确认不是画师 ID。

🔔 想关注喜欢的画师，自动接收更新？
  1. 先用 /pixiv_user_search 加画师名搜索，找到画师用户 ID。
  2. 发送 /pixiv_subscribe_add 加一个空格及该画师用户 ID，按 Bot 提示订阅。这个指令会改变当前订阅状态。
  3. 发送 /pixiv_subscribe_list 查看已订阅画师；需要取消时用 /pixiv_subscribe_remove 加画师 ID。
/pixiv_subscribe_list

订阅功能需要插件已启用定时检查且 Pixiv API 可访问；可能有群聊权限和消息频率限制。勿订阅过多导致刷屏。

定时随机推图和管理员配置指令可能修改群聊行为，不放在新手一键操作区；完整使用说明可发送 /pixiv_help。

  3. 查看返回的可能来源、原作者和相似作品，不要把相似度当成百分百正确。

🎵 怎么换城市、歌曲或搜索词？

命令由命令词 + 搜索内容组成。例如 /天气 青岛 可替换城市，/点歌 群青 可替换歌曲名；Pixiv 同理，修改角色或关键词即可。

💡当前 Pixiv 配置默认过滤 R18 内容，而且 Pixiv API 可能因代理网络波动暂时失败。“认证失败”有时实际是 SSL 连接异常，不代表用户使用了错误命令。账号和 API 授权由 Bot 管理员维护，普通用户不用提供自己的 Pixiv Token。

#sl 显示 SnowLuma 的自定义状态信息，不是所有插件的命令列表。两条指令的前缀不同，请按原样发送。

🌐 Airi / Moe / Sakura 外部节点

SnowLuma 配置中还接入了 Airi、Moe、Sakura 三个远程扩展节点。它们可以接收 QQ 事件，但本地连接配置并不提供完整的用户命令清单。

因此这里暂不列未经证实的指令，以免你发送后没有回应或误触其他功能。想查某个节点的专属玩法，需要该节点自己的帮助文档或服务端命令列表；节点掉线、过滤设置也可能让某些命令无法响应。

04 · LITTLE TIPS

还有一点小提醒

遇到问题时，不用着急。

命令发了没反应？

检查命令有没有写错，是否需要“/”前缀；群聊里聊天请正确 @小浅子。部分功能可能有冷却时间或权限限制。

游戏查询或自动签到提示未绑定？

绑定游戏 UID 和登录游戏社区是两回事。进入「游戏工具」展开对应社区的自动签到教程，按步骤登录、开启。

为什么有时回复很慢？

AI、语音、Pixiv 和游戏数据都依赖外部接口。服务繁忙或网络波动时可能变慢甚至暂时不可用。

找不到想要的功能？

先在本页上方搜索关键词，或者在 QQ 发送 /help。还可以到博客留言板反馈建议。
